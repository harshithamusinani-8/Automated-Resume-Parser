# AI Resume Analyzer 🚀

An AI-powered web application that analyzes resumes and provides meaningful insights beyond simple resume parsing.

Users can upload a PDF resume and get structured information, Resume Score, ATS Score, job-role matching, missing skills, and personalized improvement suggestions.

---

## ✨ Features

### 📄 Resume Parsing
Extracts important information from a PDF resume:

- Name
- Email
- Phone
- LinkedIn
- GitHub
- Career Objective
- Technical Skills
- Soft Skills
- Education
- Projects
- Certifications
- Achievements

### ⭐ Resume Score

Calculates an overall resume score out of 100 based on:

- Personal Information
- Career Objective
- Technical Skills
- Education
- Projects
- Certifications
- Achievements

Example:

```text
Resume Score
85 / 100
Excellent
